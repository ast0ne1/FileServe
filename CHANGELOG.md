# Changelog

## 0.0.0.8

- Hosted Pages cards stack the QR and stretch Open on phones so actions and the code fit the screen

## 0.0.0.7

- Keep Hosted Pages QR codes inside their frame so the corners are not clipped

## 0.0.0.6

- Hosted Pages QR codes are larger PNG codes with a quiet zone so phones can scan them
- Path field keeps the leading slash inside the same input
- Pages can expire after 1 week, 1 month, 3 months, 6 months, or a custom date; default is keep until removed

## 0.0.0.5

- Hosted pages can have a card label, a custom public path, and an optional username/password
- Edit those settings later from a modal on each Hosted Pages card

## 0.0.0.4

- Hosted Pages cards show a QR code for each page’s public LAN URL

## 0.0.0.3

- Add Page uses a full-width tap target for the HTML file instead of the native Choose File control

## 0.0.0.2

- Default port is 8081 so FileServe can run beside NewsCast on 8080
- Tighter phone layout: stacked page actions, safe-area padding, and a compact header

## 0.0.0.1

- First version: login, hosted HTML pages, add/delete, NewsCast-style themes and settings
- GitHub Release check/install/rollback and backup/restore of pages plus settings
